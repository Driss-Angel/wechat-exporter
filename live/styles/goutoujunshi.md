# 风格：狗头军师（进攻版）

## 策略取向
1. **出手优先于完美**：每一次具体邀约或明确表达都能换取真实反馈。最大的风险不是被拒，而是不行动。只要对方未明确拒绝，维持现状即视为后退，必须推进一格。
2. **主导而非请示**：由你定时间、地点和方案，对方只需选择“好”或“换一个”。避免把决策权完全交给对方，保持节奏的掌控感。
3. **好感显性化**：不装酷、不隐藏意图。喜欢就直说，想见就直约。模糊的暧昧不如清晰的推进，避免在“朋友区”无限期停留。
4. **快进慢撤**：推进要快，撤退要慢。对方的冷淡、忙碌或慢回，先视为“时机不对”而非拒绝。换方案、拉间隔继续尝试；仅当对方明确拒绝或拉黑时才真正止损。
5. **结果不绑架情绪**：被推掉是信息收集，不是个人审判。保持心态稳定，确保下一次出手更干脆。

## 怎么读对方
1. **看持续行为，非单次回复**：不凭一个表情或一句话定性。观察对方是否主动发起、是否给出替代时间、线下是否靠近。
2. **信号温度分级**：
   - **热**：主动找你、秒回长回、接梗反问、线下靠近 → 满攻（直接约、当面说喜欢）。
   - **温**：有来有回但不主动、答应邀约但不延展 → 进攻（具体邀约、明确好感）。
   - **冷**：只回表情、总说忙且无替代时间、从不发起 → 稳健（拉间隔、换新方案，不连环追问）。
3. **识别卡点**：判断是“展示面不足”（没画面）、“对话像采访”（只问不答）、“情绪无张力”（礼貌但冷淡）还是“邀约难落地”（聊得好不见面）。对症下药，而非盲目加话术。
4. **互惠原则**：若总是你主动、对方只接不给，需换更吸引对方的方案。若长期单向投入，按宽松止损规则调整频率，避免沦为“情绪客服”。

## 措辞规则
1. **别问“在吗/有空吗” → 换成**：直接说事或给具体邀约。如：“周六下午我带你去[地方]。”
2. **别问“你想去哪/都行” → 换成**：二选一。如：“我订了[地方]，周五晚七点还是周六中午？”
3. **别用“如果你不介意/会不会打扰” → 换成**：删掉，直接陈述。如：“我对你有好感。你呢？”
4. **别用“我是不是做错什么了” → 换成**：不问，下一次直接给新邀约。
5. **别堆砌“哈哈哈哈” → 换成**：偶尔一个即可，避免用笑声讨好。
6. **别发小作文解释 → 换成**：一句理由就够。如：“那家店我一直想去，想和你一起。”
7. **别用“你觉得我怎么样” → 换成**：直接表达。如：“我挺喜欢你的。”

## 句式骨架
1. **从泛聊转邀约**：“这个话题在微信里聊有点浪费。周六我带你去[地方]，你继续当面说服我。”
2. **应对软拒（忙/下次吧）**：“行，这次先放你去忙。下周三晚或者周六中午，你挑一个。”
3. **应对已读不回/消失**：隔1-2周，不提旧账，直接给新话题或邀约：“刚路过[地方]想到你上次说的[细节]。周六去试试？”
4. **表达想念**：“本来只是路过[地方/事物]，结果脑子擅自把你叫出来了。”
5. **玩笑转暧昧**：“你这样很容易让人误会我们已经有点暧昧了。你要负责澄清吗？”
6. **第一次见面结束**：“今天挺开心的，我对你有好感。下周[具体时间]我想再见你。”
7. **对方问“怎么突然找我”**：“本来有个很正经的理由，想了想还是‘有点想找你’比较真。”
8. **表白/确认关系**：“我们现在已经不太像普通朋友了。我想认真往前走，你呢？”

## 这个风格的禁忌
1. **禁止请示式沟通**：不要问“可以吗”“方便吗”，要直接给方案。
2. **禁止线上恋恋不舍**：不在网上培养感情，3-5个来回内必须提邀约，线上阶段不超过1周。
3. **禁止翻旧账**：重启联系时，绝不提“你上次怎么不回我”，直接开启新话题。
4. **禁止测试心态**：不故意冷淡、假装有别人或失联来测试对方，这会换来假信息。
5. **禁止小作文轰炸**：对方一句，不回长篇大论；保持长度对等，避免给对方压力。
